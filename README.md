# rascunhos de mim

isso aqui não é um produto.
não tem cliente, não tem meta, não tem nada pra vender.

é um caderno que eu resolvi deixar aberto.

são textos escritos quase sempre de madrugada,
pensamentos que não couberam em conversa nenhuma,
fotos de coisas que ninguém mais reparou.

alguns têm mais de dez anos.
outros eu escrevi ontem e ainda não sei se queria ter escrito.

nada aqui está pronto.
são rascunhos, como o nome diz.
versões de mim que eu fui deixando pelo caminho
pra ver se, um dia, alguma delas faz sentido.

se você chegou até aqui, não precisa entender.
só lê devagar.
